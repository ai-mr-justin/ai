Tentang AI Mr Justin

AI Mr Justin adalah aplikasi AI chat berbasis Cloudflare Workers dan Workers AI. Aplikasi ini mempertahankan chat history di browser pengguna dan menggunakan streaming response untuk menampilkan jawaban secara bertahap.

Versi

1.1.0 — upgrade dari aplikasi chat yang sudah berjalan.

Teknologi

  • Cloudflare Workers
  • Cloudflare Workers AI
  • TypeScript
  • HTML, CSS, JavaScript
