Dokumentasi

API chat

POST /api/chat menerima JSON berisi messages. Respons dikirim sebagai streaming Server-Sent Events.

{"messages":[{"role":"user","content":"Halo"}]}

Health check

GET /api/health memberikan status aplikasi, versi, dan model yang dikonfigurasi.

Keamanan input

Client tidak dapat menyisipkan system message sendiri. Jumlah pesan, panjang setiap pesan, dan total konteks dibatasi sebelum dikirim ke model.

Catatan

Riwayat chat versi ini disimpan di browser melalui localStorage. Jangan masukkan password, API key, token, atau data rahasia.
